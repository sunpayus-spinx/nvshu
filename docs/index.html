口径说明（请先读）
  • 识别置信度（图片模块）：识别模型的 softmax 概率（真概率口径）；低置信时自动回退/融合 Microsoft TrOCR，此时分值口径略有差异，结果的 rec_mode 字段会标明实际识别路径。低于 0.80 标「置信不足」，建议换更清晰的样本或人工复核。识别模块为第三方开源方案集成，本项目未自研识别算法。
  • 读音为字典推导的江永方言代表发音（非原书注音）；输入的调值数字（如 44、35）会自动剥离。
  • 字典未收录的读音会标出「未收录」；已收录读音的候选也可能不含你想要的字，需人工判断。

词典数据来源：unicode_nushu 字典（MIT 许可，The Nushu Coder's Group）；女书字体：Noto Traditional Nushu（OFL 许可）。 翻译模块为纯前端离线计算，输入不会上传到任何服务器；识别模块仅与你本机启动的本地服务通信。
