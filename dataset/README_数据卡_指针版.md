# 女书诗歌数据集 v4.1 · 指针版（nushu-poetry-v4.1-pointer）

发布日期：2026-10-31　|　来源版本：v4.1 修复版（6,726 行）　|　完整审计报告：`AUDIT_REPORT.md`

## 这个版本是什么

本目录是《中国女书集成》（清华大学出版社，1992，赵丽明主编/周硕沂译注）与《中国女书合集》（中华书局系）中女书诗歌文本的**机器抽取元数据 + 读音标注 + 来源指针**，共 6,726 行（JC 5,912 + HJ 814）。

**汉译文本全文不在本包内**（版权口径见下）。每行以 `hanzi_sha256`（汉译文本 SHA-256）+ 来源书名 + PDF 页码 + 书内页码作为指针：持书研究者可按指针查原书，并用哈希校验一致性。

## 版权口径（为什么是指针版）

汉译诗句逐行抽取自两部正式出版物正文，JC 部分约 4.1 万字接近整卷。民歌本身可能属公有领域，但**出版社的整理、译注、编排有独立的编辑性著作权**，整卷级汇编再发布可能超出合理使用（审计报告 §6 定级 **P0**）。因此本次发布采用审计建议的**指针路线**：

1. 公开：女书字形示意转写、读音、来源页码行号、文本哈希、质量与结构元数据；
2. 不公开：`汉译诗句`、`汉译诗句_simplified`、`原OCR`、`建议补全`（书内文本及其衍生）；
3. 后续：出版社授权推进中，取得书面授权后将在 Release 中补充全文版。

## 数据说明（已知问题，引用前必读）

1. **抽取未经完整人工核验**。全部内容由 OCR/版面分析管线自动生成，「已抽查核对」列仅 126 行（1.87%）标记核对过，且为模型辅助看图核对，非逐条人工校对。
2. **「女书拼音」为字典推导，非原书注音**（dictionary_derived_not_source_attested）。由汉译汉字反查《女书标准字字典》等资源生成，仅在汉译为同音借源字时可信；与原书字形实证读音独立对照，字位一致率约 43%（严格）/ 63%（音系骨架）。
3. **「nushu_unicode_schematic」为程序生成的示意转写，不是原书字形**。由字典候选取第一个女书字符生成，禁止用作字形研究或「女书原文」证据。
4. **质量标签（ABC）为机器启发式输出**，未人工验证。外部验证显示 A/B 区分效度不足，请勿引用「A 率」作为质量声明。
5. **重复与缺字**：完全重复行 855 条（12.7%）；含缺字占位「口」89 行；简繁混排 266 行（`dup_group_id`、`has_missing_glyph` 等列已标记）。
6. **评测污染提示**：本数据集含 10 行与 NuShuPARS 论文冻结测试集相同的文本（见 `heldout_overlap_list_pointer.csv`，按 `v2_id`/`main_row` 剔除）。在本数据集上训练后评测该测试集的结果无效。
7. 体裁分类中 40.5% 为「未分类」，不代表全部为诗歌。

## 使用限制

- 仅供科研与文化遗产保护用途，**禁止商业使用**。
- 汉译内容著作权归属原出版物著作权人；指针版仅提供定位与校验信息。
- 女书是联合国认定的濒危文化遗产，由女性创造与使用。请尊重其文化语境，产出内容避免猎奇化、娱乐化呈现。
